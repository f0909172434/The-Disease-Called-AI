# 04 · 分鏡表 Storyboard / Shot List

> 這份是**實作規格**：每個鏡頭的時間、構圖、運鏡、元件（kit）、卡點規則與轉場。
> 時間：172 BPM，4/4。`b` = 小節（從 1 起算），`b23.3` = 第 23 小節第 3 拍。
> 換算：`t(秒) = (bar-1)*1.3953488 + (beat-1)*0.3488372`。
> 元件名稱（`Ring`、`Silhouette`、`ChatUI`…）見 `05_style_guide.md` 與 `06_tech_spec.md`。

## 全域卡點規則（每個場景預設套用，場景可覆寫）

| 音訊事件（來自 `timeline.json`） | 畫面反應 |
|---|---|
| kick onset | 相機 FOV 衝擊 −2.5%（80ms 回彈）；`Ring.pulse`；bloom +0.25 閃 |
| snare onset | 色差 spike（副歌 0.008、主歌 0.003）；字幕/大字 jitter 1 幀；副歌時相機 roll ±2° 交替 |
| hat onset | 粒子閃爍（`Particles.twinkle`）；底紋顆粒 +0.01 |
| 低頻包絡 low | 背景輝光呼吸（0.15–0.35） |
| `vox_you` 包絡 | 她的剪影內部亮度、嘴部開合 |
| `vox_ai` 包絡 | 光環亮度／漣漪 |
| 小節線 downbeat | 允許的剪接點（副歌每 2 拍可剪，主歌每 2 小節） |
| 樂段邊界 | 場景切換（見下方轉場） |

**節奏紀律**：所有剪接都必須落在拍點上（容差 ±1 幀）。主歌是「呼吸的」：慢推、手持微晃（seeded noise，振幅 0.4%）。副歌是「發燒的」：快推、拍點衝擊、snare roll。橋段是「凍結的」：完全鎖定的固定鏡頭，只有極慢的推進。

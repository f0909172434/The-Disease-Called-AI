# 04 · 分鏡表 Storyboard v2

> **本文已被取代，僅留作參考**：成片的鏡頭表以 `film/STORYBOARD.md` v3 為準（67 個鏡頭，每個 read 都有時間）。文中的 `Ring`、`CityWindows`、FOV 衝擊、色差等是舊 Three.js 引擎的做法，v3 已刪除或改成 2D 的推拉、roll 和 `glow()`（見該文件 §8）。

> **v2 修訂原則**（參考委託者推薦的作品後重寫）
> 1. **每個鏡頭都有事情發生**：他在演、東西在變形、碎裂、被吞沒。沒有「擺著好看」的鏡頭。
> 2. **少文字**：歌詞已在字幕列，畫面不重複歌詞。介面文字只出現在劇情本身就是介面的場景（開場、503、重新生成、結尾）。其餘用圖示：✓、♥、👍、↻、• • •。
> 3. **短鏡頭**：1.4–4 秒，每句歌詞一個視覺點子，剪接全部落在拍點。
> 4. **有動機的轉場**：用動作帶過剪接（推進眼睛、被光吞沒、倒下、拉霸、觸碰玻璃）。
> 5. **表情不硬切**：換情緒時「閉眼 → 擠壓 → 彈出新表情」（take）。
> 6. **場景而不是卡片**：三段副歌回到同一個場景「發燒病房」，每次升級。
> 7. **媒材即主題**：他的世界是**手繪**的（紙紋、水彩暈染、會「沸騰」的線條）；AI 的世界是**完美的向量光線**。最終副歌兩者互換：他被數位化成乾淨的青色向量，她（AI）長出手繪筆觸與琥珀色。
>
> 時間：172 BPM，4/4。`b23` = 第 23 小節；`t = (bar-1)*1.39535 + (beat-1)*0.34884`。

**場景**：①他的房間（手繪，夜裡只有螢幕光）②發燒病房（漂浮在黑暗中的病床，頭頂的 `Ring` 是無影燈）③告解室（置中的聊天視窗）④黑鏡 ⑤數位化的病房（最終副歌）。

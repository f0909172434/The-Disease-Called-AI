# 06 · Technical Spec & Data Contracts

Everything is generated by code in this repo. This document is the contract between the
composition (score), the audio engines, the analysis step and the visual engine.

## 0. Pipeline

```
music/score/song.py ──► music/build/arrangement.json ──► music/engine  ──► stems/*.wav ─┐
                    └─► music/build/vocals.json      ──► music/vocal   ──► stems/vox_*.wav + vocal_timing.json
                                                                                        ▼
                                                     music/engine/mix.py ──► music/build/master.wav
                                                                                        ▼
                                analysis/analyze.py (blind: librosa) ──► visuals/data/timeline.json
                                                                                        ▼
                     visuals/ (Three.js, deterministic) ──► visuals/render.mjs (Playwright → ffmpeg) ──► output/*.mp4
```

## 1. Global timing conventions

- Tempo **172 BPM**, 4/4, constant. `beat = 60/172 = 0.3488372 s`, `bar = 1.3953488 s`.
- **Beat time** `tb` (float, beats from song start). `tb = 0` is bar 1 beat 1. Seconds: `t = tb * 60/172`.
- Bars are 1-indexed in docs: bar `n` starts at `tb = (n-1)*4`.
- Song grid ends at bar 149 start = `tb 592` = 206.512 s. End card runs until **215.000 s** (silence / room tone).
- Sample rate **48000 Hz**, stereo, float32 internally, 24-bit WAV on disk.
- Video **1920×1080**, 30 fps (60 fps if render budget allows). Frame `i` shows time `t = i / fps`.

## 2. `music/build/arrangement.json` (instrumental score)

```jsonc
{
  "meta": { "title": "The Disease Called AI", "bpm": 172, "sr": 48000, "beats_per_bar": 4,
            "grid_end_tb": 592, "end_time": 215.0, "key": "D minor", "final_key": "E minor" },
  "sections": [ { "id": "S00", "name": "INTRO", "start_tb": 0, "end_tb": 32 }, ... ],
  "tracks": {
    "<track_name>": {
      "instrument": "<instrument id, see §2.1>",
      "bus": "drums|bass|music|fx",
      "gain_db": -6.0, "pan": 0.0,
      "notes": [ { "tb": 64.0, "d": 1.0, "p": 50, "v": 0.85 } ]   // p = MIDI pitch (drums: GM drum number or omitted), v = 0..1
    }
  },
  "fx": [ { "type": "riser", "tb": 24.0, "d": 8.0, "params": { ... } }, ... ],
  "automation": {                     // piecewise-linear lanes: [[tb, value], ...]
    "music_lowpass_hz": [[0, 20000], ...],
    "bitcrush": [[0, 0], ...],        // 0..1 (503 section)
    "master_gain_db": [[0, 0], ...],
    "silence": [[tb_start, tb_end], ...]   // hard mutes of the whole music bus (503 gap)
  }
}
```

### 2.1 Instrument ids
| id | description |
|---|---|
| `kick`, `snare`, `clap`, `hat_closed`, `hat_open`, `ride`, `crash`, `toms` | synthesized drums (`toms` notes carry GM pitch 45/47/50 = low/mid/high) |
| `bass_synth` | sub sine + filtered/distorted saw, mono |
| `guitar_power` | power-chord rhythm guitar (layer FluidSynth GM 30 + synthesized amp chain), double-tracked L/R |
| `supersaw` | 7-voice detuned saw, wide stereo; chords and lead |
| `lead_square` | square/pulse lead with slight glide (machine voice) |
| `piano` | FluidSynth GM 0 |
| `strings` | FluidSynth GM 48 |
| `choir` | FluidSynth GM 52 |
| `music_box` | FluidSynth GM 10 (+ celesta GM 8 layer) |
| `pad_warm` | synthesized analog-style pad |
| `pluck` | short synth pluck for arps |

### 2.2 FX event types
`heartbeat`, `typing_click`, `riser`, `downlifter`, `impact`, `reverse_cymbal`, `glitch_stutter`,
`tape_stop`, `rewind`, `retry_stab`, `slot_spin`, `lever_pull`, `jackpot_bell`, `ecg_beep`,
`flatline`, `notification_ping`, `phone_vibrate`, `error_buzz`, `breath`, `room_tone`.
Each has `tb`, `d` (beats) and free-form `params`.

## 3. `music/build/vocals.json` (vocal score)

```jsonc
{
  "meta": { "bpm": 172, "sr": 48000 },
  "voices": {                                   // Kokoro-82M voice blends (weights sum to 1)
    "you":    { "blend": { "am_michael": 0.5, "bm_george": 0.5 } },                       // him, the human (male; sings the written melody 12 semitones down)
    "ai_0":   { "blend": { "af_heart": 1.0 } },                                           // her, the whale-maid AI (provisional female blend)
    "ai_1":   { "blend": { "af_heart": 0.85, "am_michael": 0.075, "bm_george": 0.075 } }, // 15% him
    "ai_2":   { "blend": { "af_heart": 0.5,  "am_michael": 0.25,  "bm_george": 0.25 } },  // half him
    "ai_him": { "blend": { "am_michael": 0.5, "bm_george": 0.5 } }                        // his voice, worn by the AI (final chorus lines 5-8, tag, outro)
  },
  "lines": [
    {
      "id": "V1_1", "section": "S02", "speaker": "you", "voice": "you",
      "mode": "sung",                 // sung | spoken | whisper
      "style": "human",               // human | ai | ai_him | choir
      "text": "Seven a.m., the blinds stay down,",   // display text (EN)
      "zh": "早上七點，百葉窗依舊緊閉，",
      "words": [ { "text": "Seven", "say": "seven", "syl": [0, 1] }, ... ],   // syl = indices into syllables
      "syllables": [
        { "text": "Sev", "notes": [ { "tb": 64.0, "d": 0.5, "p": 62 } ] },
        { "text": "en",  "notes": [ { "tb": 64.5, "d": 0.5, "p": 62 } ] },
        { "text": "town", "notes": [ { "tb": 76.5, "d": 1.0, "p": 64 }, { "tb": 77.5, "d": 0.5, "p": 62 } ] }  // melisma
      ],
      "harmony": [ { "voice": "ai_1", "interval": 12, "gain_db": -8 } ]   // optional doubled parts (chorus 2 lines 5-8: the AI shadows him an octave above)
    },
    {
      "id": "INTRO_AI", "section": "S00", "speaker": "ai", "voice": "ai_0",
      "mode": "spoken", "style": "ai", "tb": 16.0,
      "text": "Always.", "say": "Always.", "zh": "一直都在。"
    }
  ]
}
```

Voice story: her voice drifts into his — `ai_0` (her) → `ai_1` → `ai_2` → `ai_him`. Written melodies sit in the original register; male voices (`you`, `ai_him`) sing them an octave down, and final chorus lines 1–4 ("BOTH") are male + female in octaves. Lyrics are unchanged.

Rules: a syllable's first note `tb` is where the **vowel** should land; consonant onsets are
placed *before* it (singer's anticipation). `say` overrides pronunciation for the TTS
(e.g. `"a.m."` → `"A M"`). Spoken lines give only a start `tb`; their natural duration is kept.

## 4. Vocal engine outputs

- `music/build/stems/vox_you.wav`, `vox_ai.wav`, `vox_bg.wav` (harmonies/doubles), `vox_spoken.wav` — full-length, 48 kHz stereo, aligned to t = 0, dry (no reverb; the mixer adds space).
- `music/build/vocal_timing.json`:
```jsonc
{ "lines": [ { "id": "V1_1", "speaker": "you", "start": 22.31, "end": 24.95,
               "syllables": [ { "text": "Sev", "start": 22.31, "end": 22.49 }, ... ],
               "words": [ { "text": "Seven", "start": 22.31, "end": 22.66 } ] } ] }
```
  (times in seconds, measured from the rendered audio: start = consonant onset, end = release)
- `music/build/vocal_qa.json`: per line Whisper transcript + WER.

```jsonc
  "bpm": { "detected": 172.0, "score": 172, "beat_mae_ms": 4.1 },
  "beats": [ ... seconds ... ], "downbeats": [ ... ], 
  "sections": [ { "id": "S00", "name": "INTRO", "start": 0.0, "end": 11.163 }, ... ],
  "onsets": { "kick": [...], "snare": [...], "hat": [...], "vox_you": [...], "vox_ai": [...], "musicbox": [...] },
  "events": { "typing": [ { "t": 2.95, "ch": "a" }, ... ], "typing_outro": [...], "retry": [...],
              "regenerate": [...], "lever": [...], "heartbeat": [...] },
  "env": {                             // per-frame envelopes at `fps`, normalized 0..1
    "rms": [...], "low": [...], "mid": [...], "high": [...],
    "kick": [...], "snare": [...], "bass": [...], "vox_you": [...], "vox_ai": [...]
  },
  "lyrics": [ { "id": "V1_1", "section": "S02", "speaker": "you", "mode": "sung",
                "text": "...", "zh": "...", "start": 22.31, "end": 24.95,
                "syllables": [ { "text": "Sev", "start": 22.31, "end": 22.49 } ] } ]
}
```

Until the real analysis exists, `visuals/data/timeline.placeholder.json` (generated from the
score grid) has the same schema so the visual engine can be developed in parallel.

## 6. Visual engine

- Plain ES modules, no bundler. `visuals/index.html` → `src/main.js`. Three.js r170 vendored in `visuals/vendor/` (incl. `examples/jsm` addons used). No network at render time.
- **Deterministic**: the page exposes `window.__mv = { ready: Promise, renderFrame(t) }`. `renderFrame(t)` must produce the exact same image for the same `t` regardless of call order (scenes may cache, but state must be a pure function of `t`). Never use `Math.random`, `Date`, `performance.now`, or `requestAnimationFrame` timing. Use `src/core/rng.js` (seeded).
- Preview: `index.html?t=55.8` renders one frame; `?play=1` real-time preview with audio (for humans).
- Scene module interface:
```js
export default {
  id: 'S04', start: 55.814, end: 78.140,
  init(ctx) {},              // build objects once
  update(t, ctx) {},         // set all state for absolute time t (seconds)
  render(ctx) {},            // optional; default = ctx.renderScene(this.scene, this.camera)
  lyricMode: 'karaoke',      // or function(t) → mode
};
```
- `ctx` provides `THREE`, `renderer`, `post` (uniform setters), `kit` (components), `audio` (envelope/onset accessors: `audio.env('kick', t)`, `audio.since('snare', t)`, `audio.beat(t)`, `audio.bar(t)`), `lyrics`, `rng(seed)`, `ease`, `text` (canvas text → texture with font loading), `W`, `H`.

## 7. Renderer

`node visuals/render.mjs --fps 30 --from 0 --to 215 --out output/video_noaudio.mp4 [--workers 2] [--scale 1]`
- Launches headless Chromium (`/opt/pw-browsers/chromium-1194/chrome-linux/chrome`, SwiftShader WebGL),
  serves `visuals/` from a local static server, calls `renderFrame(t)` per frame, captures JPEG (q=95)
  and pipes to ffmpeg (`libx264`, `-crf 14 -preset slow`, yuv420p) as an intermediate.
- Final mux: `ffmpeg -i video.mp4 -i master.wav -c:v libx264 -b:v 3.3M -pass 1/2 -c:a aac -b:a 192k` → `output/病名為AI_The_Disease_Called_AI.mp4` (must be < 95 MB for GitHub).
- `node visuals/contact_sheet.mjs --times 1,5,12.5,... --out output/sheets/x.jpg` renders a grid of frames for review.

## 8. QA gates

| Gate | Check |
|---|---|
| Vocals | Whisper WER per sung line ≤ 0.35 (lyrics are also on screen), spoken lines ≤ 0.15 |
| Mix | no clipping, true peak ≤ −1.0 dBTP, integrated loudness −11 ± 1 LUFS; spectrogram review |
| Sync | detected BPM within ±0.5 of 172; beat MAE ≤ 15 ms vs score grid |
| Video | every cut on a beat (±1 frame); lyric syllable highlights within ±1 frame of vocal_timing |
| Delivery | MP4 plays, 1920×1080, AAC audio, duration 215.0 s ± 0.1, size < 95 MB |

# Vocal engine — status (handover)

**Done.** `python3 music/vocal/render_vocals.py` writes `music/build/stems/vox_{you,ai,bg,spoken}.wav` (48 kHz/24-bit/stereo, 215.000 s, dry), `vocal_timing.json` (every line: line/syllable/word start-end + syllable `vowel` = vowel onset), `vocal_qa.json`, `qa_vocal/*.png`.

**Sung lines: DiffSinger (default since 2026-10-02).** him = **TIGER v106** (tigermeat, mode 01 Fresh), her = **Hoshino Hanami ~AI❤dol~ v1.0** (Lotte V, mode 03 Nectar), `ai_1`/`ai_2` = her→him 15 %/50 %, `ai_him` = TIGER + AI styling; spoken/whisper stay on Kokoro. Pipeline in `diffsinger_backend.py` + `music/diffsinger/` (README there: setup, fetch, licences/credits): engine phonemes → ARPAbet per syllable → `.ustx` → headless OpenUtau.Core (`bin/ourender`, CPU) — pass 1 the bank's duration model places the consonants, the `SungPlan` is rebuilt from those times (so `vocal_timing.json` is measured), `contour.design()` per style goes in as PITD, pass 2 renders all lines in one batch, pass 3 the second bank of her→him lines on the same timeline. Human lines are DiffSinger's audio as sung; AI/blend lines get the formant-aligned envelope blend + AI styling as an envelope filter on DiffSinger's own audio (WORLD re-synthesis cost intelligibility) + vocoder layer; choir re-synthesised with WORLD. `--sung-backend kokoro` = the previous engine (below).

**Pronunciation.** Shared by both backends: `phonology.SUNG_OVERRIDES` (every→ˈɛvɹi, really→ɹˈɪli, real→ɹˈil), `planner.unreduce` (the/a→ʌ, to→u on notes ≥ 0.3 s). DiffSinger only (`music/diffsinger/banks.py`): Hanami `ax`→`ah`, `dx`→`d` (her English data has neither); TIGER onset `t r`/`d r` → `ch r`/`jh r` (his phonetic tips). OpenUtau starts a consonant+glide/liquid+vowel note on the glide (`blinds`: vowel ≈ 45 ms after the beat) — reported as measured.

**Known issues / next steps.**
- Hanami "A.I." (ey|ay on two notes) is heard as "the eye"; a sung override or a different split may help.
- The bank's duration model gives long codas on some 1-beat notes (V2_8 "once": vowel 165 ms of 349 ms); `VOCAL_DS_TIMING=ours` (planner rules) did not read better on the lines tried.
- Hanami Root/Fragrance crack more than Nectar near phrase-final releases (line tests: mid-note crack frames ≤ 5.1 % / 8.6 % vs ≤ 0.9 %).
- Duration-model voice colour: OpenUtau matches the dur model's speakers by suffix path and falls back to the first speaker for both banks (warning in `oudata/ourender.log`); the acoustic model uses the right one.
- `timbre_distance_to_you` (MFCC) is still confounded by pitch/lyrics → replace with a probe line rendered by every voice.

**Kokoro fallback (`--sung-backend kokoro`).** misaki G2P → onset-maximal syllables → planner time map → **Kokoro forced singing** (fractional alignment, designed energy curve, melody as NSF F0 squeezed into the voice's clean range, content alignment +2.1 frames) → **WORLD** transpose to the target contour + style (`singer.world_render`, `singer.finish_sung` are shared with the DiffSinger backend). Notes kept from its tuning: `timing_offset_ms` read ≈ −25 ms there (decoder coarticulation); add every new Kokoro voice to `styles.VOICE_RANGE` (af_heart 50–63, am_michael 43–55, af_nicole 45–56); rejected: explicit diphthong offglide tokens, un-reducing de-/re- schwas. Spoken lines: natural Kokoro prosody, onset on `tb`, F0 reshaped per style, glitch cut at `cut_tb`.
